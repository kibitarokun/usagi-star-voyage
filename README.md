# うさぎの宇宙航路

ワープから始まり、9つのステージを進むブラウザー向け3Dシューティングゲームです。タイトルから開始ステージを選べます。

## 起動

このフォルダで `python3 -m http.server 4173` を実行し、ブラウザーで `http://127.0.0.1:4173/` を開きます。ES Modules と WebGL を使うため、ファイルを直接開かずローカルサーバー経由で起動してください。

## 操作

- PC: 矢印キーまたは WASD で移動、Space を押している間だけ射撃
- スマートフォン: 画面を押しながらドラッグで移動・射撃
- 音 ON/OFF と一時停止は画面右下にあります。初回出撃時に音が有効になります（ブラウザーの音声許可が必要です）。

BGM は Web Audio API で生成し、一部の SE は assets/sounds の音源を使用します。

## 追加戦域

- STAGE 06 紫電の星雲：蛇行・旋回する2機編隊。18機撃破で突破。
- STAGE 07 灼熱の小惑星帯：3機編隊と狙いを固定して突進する敵。24機撃破で突破。
- STAGE 08 超旗艦エクリプス：耐久力240、立体弾幕と3本の予告付きビーム。耐久力半分以下で攻撃が激化。
- ステージ5の旗艦撃破後も航行を続行。各戦域間ではシールドが1回復します。

## テスト

STAGE 09 は惑星要塞オブリビオン攻略戦です。滑走路から発進する防衛隊15機を撃破し、耐久力340の基地コアを破壊するとゲームクリア。基地は耐久力半減後に砲撃が激化します。ステージ9で再挑戦すると防衛隊との戦いから再開します。

ゲームオーバー後は「ステージNに再挑戦」で同じ戦域を繰り返し遊べます。シールドは全回復し、敵・ボス・撃破数はリセット、スコアはそのステージ開始時に戻ります。「ステージ1からやり直す」も選べます。再読み込み後の進行保存はありません。

`node --test test-progression.mjs test-audio.mjs`
